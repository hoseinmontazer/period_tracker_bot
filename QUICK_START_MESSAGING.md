# 🚀 Quick Start - Partner Messaging (2 Minutes)

## Step 1: Start the Bot (30 seconds)
```bash
python bot.py
```

Look for: `🤖 Period Tracker Bot is running...`

---

## Step 2: Test Messaging (1 minute)

### In Telegram:

1. **Open Messages**
   ```
   /messages
   ```

2. **Send a Message**
   - Click "✉️ Send Message"
   - Type your message
   - Done! ✅

3. **View Conversation**
   - Click "💬 View Conversation"
   - See your message history

---

## Step 3: Verify (30 seconds)

### Check These Work:
- [ ] `/messages` command responds
- [ ] Can send a message
- [ ] Can view conversation
- [ ] Unread count shows correctly

---

## ✅ Success!

If all checks pass, your messaging system is working!

### What Users Can Do Now:
- 💬 Send messages to partner
- 📱 Receive message notifications
- 💌 View full conversation
- 🔔 Get unread count
- ⚡ Quick reply from notifications

---

## 🎯 Quick Commands

```bash
/messages           # Open messages menu
/notifications      # View system notifications
/notif_settings    # Manage preferences
```
